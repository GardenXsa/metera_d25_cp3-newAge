# GIF Asset Attribution

The base and meme GIFs in this folder are local generated assets for the Scene Visual Library.

They were created procedurally for this project and are recorded in `data/visual_assets.json` with:

- `source: "local_generated"`
- `license: "project_generated"`
- `artist: "OpenAI Codex / project procedural pack"`

Adult/explicit local-pack slots are intentionally left empty and must be supplied by the project owner.
